## 📋 Step-by-Step GitHub Setup:

### 1. Create Repository
- Go to **github.com**
- Click **"New repository"**
- Name: **NeuraShield.AI**
- Description: **Self-Learning AI Guardian for Modern DevOps**
- ✅ **Public** (required for free GitHub Pages)
- Click **"Create repository"**

### 2. Upload Code
Run these commands:
```bash
git remote add origin https://github.com/YOURUSERNAME/NeuraShield.AI.git
git branch -M main
git push -u origin main
```

### 3. Enable GitHub Pages
- Go to repository **Settings**
- Scroll to **Pages** section
- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**
- Click **Save**

### 4. Your Live Site
After 2-3 minutes:
**https://YOURUSERNAME.github.io/NeuraShield.AI**
