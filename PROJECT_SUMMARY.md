## 🚀 Running the System

### Quick Demo (No Dependencies)
```bash
cd NeuraShield.AI
py run_demo_ascii.py
```

### Full System Launch
```bash
# Install dependencies
pip install -r requirements.txt

# Start infrastructure
docker-compose up -d

# Launch API server
py start_neurashield.py

# Access dashboard
# API: http://localhost:8000
# Frontend: http://localhost:3000
```

### CLI Usage
```bash
# Analyze code
py -m app.cli analyze --path .

# Security scan
py -m app.cli scan --path .

# Pipeline optimization
py -m app.cli optimize
```
