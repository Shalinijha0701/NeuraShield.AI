NeuraShield.AI - Vercel Deployment Instructions

STEP 1: Login to Vercel
Run: vercel login
Choose: GitHub/Google/Email

STEP 2: Deploy
Run: vercel
Answer prompts:
- Project name: neurashield-ai
- Deploy: y

STEP 3: Get Live URL
Vercel will show: https://neurashield-ai-xxx.vercel.app

ALTERNATIVE - Web UI (Easier):
1. Go to vercel.com
2. Sign up with GitHub
3. Click "Add New Project"
4. Upload your NeuraShield.AI folder
5. Click Deploy
6. Live in 30 seconds!
